# 山豬氣象特攻隊｜Boar Weather Rangers

以六角格反作用力移動玩法帶領學生認識天氣要素、依資料預測短期天氣，以及分辨天氣與氣候。支援繁體中文、English、한국어。

## 適用對象

國小中高年級（設計假設，實際年級與課本版本請教師確認）。自然科單元：115學年度康軒版單元一「探索天氣的變化」。

## 三個任務

1. 天氣要素觀測：氣溫、雲量、風向、風速、降雨共同描述天氣。
2. 天氣變化預測：根據連續觀測線索推論，不把預測當成保證。
3. 氣候資料整理：使用標明為教學示意的多年資料討論長期趨勢。

## 操作方式

選擇地圖方向，預覽探測球路徑與山豬受到的反作用力位移，再按「發射探測球」。觸控可點選方向按鈕；鍵盤可使用方向鍵或 WASD 瞄準、Enter 發射。探測球只是遊戲化探測工具；實際上反作用力不只在真空中發生，此簡化不代表真實動物能靠發射物移動。

## 開啟

直接以瀏覽器開啟 `index.html`，無需安裝依賴。

## 課綱對應

依使用者提供的活動名稱規劃，正式課綱代碼及版本適配待教師依正式課綱與課本確認；本教材不自行杜撰代碼或宣稱引用課本原文。

## 授權與資料

本專案為原創教學示意遊戲。第三關多年資料均為教學示意資料，並非中央氣象署觀測值。
