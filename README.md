# 山豬氣象特攻隊｜Boar Weather Rangers

一款全螢幕六角格競技場式自然科任務遊戲。玩家駕駛野外裝備車發射氣象探測球，利用反作用力改變位置，在山區風場中連線觀測站、掃描資料並撤離。支援繁體中文、English、한국어。

## 設計假設

國小中高年級；自然科單元為 115 學年度康軒版單元一「探索天氣的變化」。適用年級與課本細節待教師確認。

## 遊戲任務

1. **風暴前哨：**透過觀測站讀取氣溫、雲量、風向、風速與降雨。
2. **預測窗口：**讀取連續觀測摘要，登錄對下一時段天氣的推測。
3. **長期訊號：**掃描多年摘要資料，分辨天氣事件與氣候規律。

遊戲不採教材網站的頁籤或卡片導覽。玩家從基地部署，在競技場 HUD 查看任務目標、裝備、風場與通訊紀錄；教材概念透過任務簡報、場上掃描資料、玩家預測與撤離結算呈現。

## 操作

- 方向鍵或 WASD 瞄準；觸控也可使用方向按鈕。
- Space 或 Enter 發射探測球；E 掃描已連線的資料點。
- 發射前觀察探測球路徑與裝備車反向推進路徑；取得資料後再次發射可主動撤離並結算。
- 直接以瀏覽器開啟 `index.html`，無需安裝依賴。

反作用力不只在真空中存在；遊戲把力與位移簡化為六角格推進，不代表真實山豬能靠發射探測器移動。預測是根據資料形成、可依新證據修正的推論。第三關多年資料明確標示為教學示意，並非官方實測。
