# 教學設計概要

## 藍圖
- 年級：國小中高年級假設；教師確認後可調整。
- 領域：自然科學；單元一「探索天氣的變化」。
- 時間：三關約 30–40 分鐘，可分節進行。
- 先備：能讀取簡單表格、方向與數字。
- 目標：辨認天氣要素；用多項、連續觀測資料提出可修正的預測；分辨短期天氣與長期氣候趨勢。
- 核心素養：觀察、資料判讀、推論、以證據說明與修正想法。
- 頁籤：任務簡報、活動1、活動2、活動3、原理探索、生活應用、闖關挑戰、自主學習。
- 生活連結：出門穿著、登山觀天、雨具準備、長期氣候圖表閱讀、野生動物棲地。
- 評量：三關預測與解釋、即時回饋、三題綜合挑戰。
- 課綱代碼：待教師依正式課綱手冊確認。

## 科學說明
天氣要素是描述某時某地大氣狀況的觀察項目，不等於單一因素造成所有天氣變化。天氣預報是根據資料形成、可因新證據調整的推論。氣候須以較長時間資料觀察規律；單次天氣事件不足以代表長期趨勢。遊戲反作用力是方便操作的類比：發射探測球時探測球與角色方向相反；物理反作用不以真空為條件，遊戲中的位移數值則為簡化規則。
